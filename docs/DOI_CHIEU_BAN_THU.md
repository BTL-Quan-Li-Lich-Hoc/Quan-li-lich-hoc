# Bản thử đối chiếu Nhom10

Mã nguồn ứng dụng, các bài kiểm tra và phần Android của bản thử
được lấy từ repo LonelyChromosome/nhom10, mã
4a8d13a939cd9766db83dbd1b0e6e4da37948932.

Đây là bản thử để so sánh khả năng chạy và chức năng. Các thay đổi
trước đó của nhóm Lập trình di động vẫn còn trong lịch sử nhánh và
các nhánh thành viên, chưa đưa vào main.

README chính giữ nội dung phân công của nhóm Lập trình di động.
Giữ giấy phép và thông báo nguồn từ bản Nhom10.

Muốn kiểm tra nhanh:
- bash tool/bootstrap.sh
- flutter analyze --no-fatal-infos --no-fatal-warnings
- flutter test
- flutter build apk --release

Việc build thành công chưa xác nhận đăng nhập với QLĐT thật
hoặc hoạt động của widget trên điện thoại cụ thể.
